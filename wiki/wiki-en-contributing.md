# 🤝 Contributing to TITAN-LAB

Thank you for your interest in contributing to TITAN-Interactive-Cosmos-Lab!

---

## Code of Conduct
- Be respectful and professional.
- Base all discussions on scientific accuracy and technical rigor.
- Any harassment or dishonest claims of authorship will result in immediate ban.

---

## How to Contribute

### 🐛 Bug Reports
1. Open an [Issue](https://github.com/cyberenigma-lgtm/TITAN-Interactive-Cosmos-Lab/issues)
2. Use the **Bug Report** template
3. Include browser, OS, and reproduction steps

### 💡 Feature / Module Proposals
1. Open an [Issue](https://github.com/cyberenigma-lgtm/TITAN-Interactive-Cosmos-Lab/issues)
2. Use the **Module Idea** template
3. Describe the scientific basis and visual goals

### 🔭 Scientific Contributions
1. Open an [Issue](https://github.com/cyberenigma-lgtm/TITAN-Interactive-Cosmos-Lab/issues)
2. Use the **Scientific Research Proposal** template
3. Include your institutional affiliation and objectives

### 🏛️ Institutional Requests
1. Open an [Issue](https://github.com/cyberenigma-lgtm/TITAN-Interactive-Cosmos-Lab/issues)
2. Use the **Institutional Request** template

---

## Pull Request Guidelines

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-module-name`
3. Commit with descriptive messages
4. Keep code clean, commented, and documented
5. Open a PR against `main` — describe what changed and why
